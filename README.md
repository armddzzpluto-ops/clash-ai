# CLASH AI — สนามประลองไอเดีย ⚔️

Mini Project เว็บไซต์จำลองการอภิปรายด้วยระบบวิเคราะห์เชิงกฎ ผู้ใช้พิมพ์ประเด็น แล้วระบบจะแสดงเหตุผลฝ่ายเห็นด้วยและไม่เห็นด้วย 3 รอบ ก่อนประเมินรูปแบบการให้เหตุผลและเปิดให้ผู้ใช้โหวต

## ทดลองใช้งาน

เปิดเว็บไซต์ผ่าน GitHub Pages: `https://armddzzpluto-ops.github.io/clash-ai/`

หากลิงก์ยังไม่เปิด ให้เข้า **Settings → Pages → Source: Deploy from a branch → Branch: main / root → Save** แล้วรอประมาณ 1–3 นาที

## ฟังก์ชันหลัก

- วิเคราะห์หมวดของหัวข้อจากคำสำคัญ เช่น การเรียน งาน เทคโนโลยี การเงิน และสังคม
- สร้างเหตุผลสองฝ่าย 3 รอบ: เปิดประเด็น โต้แย้ง และปิดประเด็น
- แสดงทีละฝ่าย พร้อมย้อนกลับและเล่นอัตโนมัติ
- ให้คะแนนความชัดเจน ความตรงประเด็น และการตอบข้อโต้แย้ง
- ผู้ใช้โหวตและคัดลอกสรุปผลได้
- เก็บประวัติ 8 รายการล่าสุดใน Local Storage
- รองรับคอมพิวเตอร์ โทรศัพท์ คีย์บอร์ด และโหมดลดการเคลื่อนไหว

## AI มีส่วนร่วมอย่างไร

AI ถูกใช้ช่วยคิดแนวคิด ออกแบบหน้าจอ เขียนและตรวจโค้ด รวมถึงวางโครงเหตุผลตัวอย่าง ภายในเว็บใช้ **AI Simulation แบบ Rule-based** ซึ่งวิเคราะห์คำสำคัญของหัวข้อแล้วประกอบเหตุผลตามหมวดโดยอัตโนมัติ จึงเปิดบน GitHub Pages ได้ทันทีและไม่ต้องเปิดเผย API Key

คะแนนในเว็บวัดรูปแบบการให้เหตุผล ไม่ได้ยืนยันความจริงของแต่ละฝ่าย และระบบไม่ได้ค้นข้อมูลจากอินเทอร์เน็ต ผู้ใช้ควรตรวจข้อเท็จจริงก่อนนำผลไปใช้
